* **Один CSV — все платформы.** Выгружаете оценки с любого поддерживаемого сервиса и загружаете в любой другой. Файл обычный, читаемый CSV — он же и резервная копия, которая остаётся у вас.
* **Два режима импорта.** *Импорт* только заполняет пропуски и пропускает фильмы, которые уже оценены (`IMDb id` / id Кинопоиска / slug Letterboxd переиспользуются, а не ищутся заново). *Жёсткий импорт* перезаписывает существующие оценки — кнопка называется **Заменить всё** и спрашивает подтверждение перед стартом.
* **Сопоставление, которое не угадывает.** Сначала по id, затем по точному названию, транслитерации, допуску по году и альтернативным названиям. Совпадающее слово в середине названия ничего не даёт, а расхождение по году блокирует запись — оценка не попадёт на одноимённый фильм только потому, что названия похожи.
* **Рассчитано на большие библиотеки.** Результаты поиска кэшируются в IndexedDB (7 дней), уже оценённые фильмы отсекаются до сетевых запросов, а скорость запросов подстраивается под ответы `429 / Retry-After`.
* **Избранное.** Фильмы, отмеченные в CSV как избранные, можно добавить в избранное целевого профиля.
* **9 языков интерфейса.** Английский, русский, испанский, французский, немецкий, португальский, китайский, японский и корейский — переключаются в панели.

## Установка

### Расширение для браузера (рекомендуется)

Расширение содержит тот же движок в виде штатного WebExtension, поэтому продолжает работать, когда сайт ужесточает CSP.

* **Firefox:** установите из [Mozilla Add-ons](https://addons.mozilla.org/firefox/addon/movie-rating-sync/) или подключите `extension/manifest.firefox.json` через `about:debugging#/runtime/this-firefox` → *Load Temporary Add-on*.
* **Chrome / Edge:** откройте `chrome://extensions` (или `edge://extensions`), включите **Developer mode**, нажмите **Load unpacked** и выберите папку `extension`.
* Круглая кнопка-стрелка появляется в правом нижнем углу страниц Кинопоиска, IMDb и Letterboxd.

### Userscript

1. Установите менеджер скриптов — [Tampermonkey](https://www.tampermonkey.net/) (рекомендуется) или [Violentmonkey](https://violentmonkey.github.io/).
2. Откройте [`movie-rating-sync.user.js`](movie-rating-sync.user.js) в этом репозитории и нажмите **Raw** — менеджер предложит установку.
3. Обновления приходят автоматически по `@updateURL` из заголовка скрипта.

## Использование

1. Войдите на **исходный** сервис (например, Кинопоиск) и нажмите **Экспорт оценок** — скачается CSV-файл.
2. Войдите на **целевой** сервис (например, IMDb).
3. Нажмите **Импорт** (или **Жёсткий импорт → Заменить всё**, чтобы перезаписать оценки), выберите CSV и следите за панелью прогресса.
4. При необходимости включите **Импорт избранного**, чтобы избранное из CSV добавилось на целевом сайте.

Каждый запуск заканчивается счётчиками — `Оценено`, `Просмотрено`, `Пропущено`, `Не найдено`, `Ошибки` — и файлом **missed**, который можно подать на второй запуск.

## О сопоставлении

Кросс-сервисное сопоставление — самая сложная часть проекта, и правила намеренно консервативные:

* Точный id (`tt…`, id фильма Кинопоиска, slug Letterboxd) всегда важнее любых совпадений по названию.
* Для `точного` совпадения названия ещё нужен совместимый год выпуска (или его отсутствие).
* Для совпадения по `подстроке` год должен совпадать; жёсткий импорт снижает порог уверенности, но никогда — порог года.
* Русские и английские названия связываются через транслитерацию и подсказки самого IMDb, и только при совпадении года.
* Letterboxd→IMDb определяется по самой странице фильма (`More at imdb.com/title/…`) — это точный id, а не догадка по названию.

Редкие, региональные или ещё не вышедшие фильмы всё равно могут отсутствовать на целевом сервисе. Они попадают в файл missed, а не превращаются в неверную оценку.

## Разработка

Userscript — единственный источник правды, расширение генерируется из него.

* `node --check movie-rating-sync.user.js` — проверка синтаксиса.
* `node tools/build-extension.js` — **обязательно после каждого изменения скрипта**: пересобирает `extension/content.js` (шим `GM_*` живёт в этом инструменте, а не в userscript).
* `node tests/extension-build.test.js` — сверяет собранное расширение с userscript (версия, шим, кнопка запуска).
* `node tests/pure-functions.test.js`, `node tests/i18n.test.js`, `node tests/match-guards.test.js`, `node tests/title-key.test.js` — юнит-тесты и проверки паритета.
* `node tests/matcher-harness.js` — прогон сопоставления по реальным CSV в репозитории; флаги `--limit`, `--filter`, `--trace`.
* Ручной чек-лист: [`MANUAL_TEST_GUIDE.md`](MANUAL_TEST_GUIDE.md).

Релизы: пуш новой версии `@version` в `main` запускает `.github/workflows/release.yml` — он собирает пакет для Firefox, публикует его в Mozilla Add-ons и создаёт GitHub-релиз с тегом.

## Приватность

Скрипт обращается только к сайтам, где вы уже авторизованы. Телеметрии и сторонних серверов нет — см. [PRIVACY.md](PRIVACY.md).
